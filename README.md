# مصاريفي
تطبيق Flutter بسيط لإدارة المصاريف الشخصية.
المميزات الحالية:
- تحديد الرصيد.
- إضافة مصروف بالاسم والمبلغ.
- عرض إجمالي المصاريف والرصيد المتبقي.
- حذف المصروف.
- حفظ البيانات محليًا على الجهاز.

للتشغيل:
1. ثبّت Flutter.
2. داخل مجلد المشروع شغّل: flutter pub get
3. ثم: flutter run
ولإنشاء APK: flutter build apk --release
